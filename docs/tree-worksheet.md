# The Tree Worksheet

Your canvas (started 2026-08-30). The whole tree in one ascii drawing — the settled barebones
ages written in, every open slot marked `[ ________ ]` for you to fill, each with a hint of
the *role* it should serve. Edit freely; when an age reads done, say "fold age N" and it gets
implemented as drawn. The parts bin under each age lists everything already designed (from
`docs/tech-tree.md` Part 3 and the built rows) that you can drop into a slot or strike out.
A node earns its place by the house rule: **it upgrades a unit, enables a key mechanic, or
enables a building you plan around.**

Legend: `──` prereq · `★` wonder home · `Δ` mechanic switch · UPPERCASE = a system turning on.

## The rules the fold will apply (so you don't have to track them)

Cut nodes' wonders re-home to the nearest survivor · unit upgrade chains stay unbroken ·
every mechanic switch (Δ) keeps exactly one home · ids never change, names are data · the
chart re-lays and the pacing seed re-measures after each age folds.
