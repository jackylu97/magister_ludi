Fonts

Five font treatments, from occult and serious to playful and silly. Each one sets the same game copy. Choose one treatment. Then the other boards will use it.

All fonts come from Google Fonts. No treatment uses blackletter: the art pass refuses it.

The board titles and these notes use the placeholder faces. Each row shows its own treatment.
